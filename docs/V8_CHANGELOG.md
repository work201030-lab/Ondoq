# V8 — Production hardening

## أهم الإصلاحات

- إصلاح حذف حساب العيادة: أصبحت جداول المواعيد والإشعارات تتبع الحذف المتسلسل، لذلك لا يفشل حذف العيادة بسبب قيود PostgreSQL.
- إضافة migration مستقلة لقواعد البيانات الموجودة بالفعل.
- إضافة rate limit خاص بمسارات المصادقة.
- رفض تشغيل الـ API إذا لم يكن `JWT_SECRET` قويًا (32 حرفًا على الأقل).
- تحسين التحقق من البريد وSlug وكلمة المرور.
- منع كشف وجود الحسابات من endpoint طلب الحذف الخارجي.
- إضافة إنشاء المرضى لصاحب العيادة/موظف الاستقبال.
- تطبيق حد المواعيد الشهري الموجود في خطة الاشتراك.
- تحسين التحقق من التاريخ والوقت قبل إنشاء الموعد.
- الإبقاء على فحص Release واختبارات الـ smoke tests.

## ما لم يتم ادعاؤه

لم يتم إنشاء AAB فعلي داخل هذه البيئة لأن Android SDK/Gradle غير متاحين هنا. بناء AAB النهائي يجب أن يتم على بيئة Android فعلية أو CI مجهز بـ Android SDK، ثم توقيع الإصدار بمفتاح Release محفوظ خارج المستودع.
